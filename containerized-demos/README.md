# Containerized Demos

This directory contains containerized demonstrations for various AI and ML use cases. Each subdirectory focuses on a specific domain and includes related demos.

## Available Demo Categories

### Model Serving

Machine learning [model serving](model-serving/) demonstrations using ONNX Runtime and Triton Inference Server:

* **Iris Classification**
* **Fraud Detection**

*More demo categories will be added in the future.*

## Shared Resources

The `shared/` directory contains common resources used across multiple demos:

* **`Containerfile`**: Container image definition with Python 3.12 and required dependencies
* **`requirements.txt`**: Python package dependencies used by the demos
